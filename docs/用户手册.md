## 简介

TapMC 是一款现代化的 Minecraft 启动器，支持：
- ✅ 多平台：Android / iOS / Windows / macOS / Linux / Web
- ✅ 多实例管理
- ✅ 模组管理（Fabric / Forge）
- ✅ Java 版本自动探测
- ✅ 实时游戏日志

---

## 安装

### Windows/macOS/Linux

1. 从 GitHub 下载最新版本
2. 解压压缩包
3. 运行 `TapMC` 或 `tapmc`

### Android/iOS

1. 从 GitHub 下载 APK/IPA
2. 安装到设备
3. 打开应用

### Web 版本

1. 访问我们的 Web 页面
2. 直接在浏览器中使用

## 快速开始

### 1. 启动 TapMC
- 首次启动会自动探测 Java 运行时
- 如果未找到 Java，请安装 JDK 8-25

### 2. 创建第一个实例
- 点击「创建实例」按钮
- 输入实例名称
- 选择模板（默认/生存模式）

### 3. 启动游戏
- 在实例列表中选择你的实例
- 点击「启动游戏」按钮
- 游戏将在新窗口中打开

## 功能指南

### 实例管理

#### 创建实例
1. 点击右上角的「+」按钮
2. 输入实例名称
3. 选择模板（可选）
4. 点击「创建」

#### 删除实例
1. 在实例列表中找到要删除的实例
2. 点击「删除」按钮
3. 确认删除

#### 重命名实例
- 目前支持在创建时设置名称
- 后续版本将支持重命名

### 模组管理

#### 启用模组
1. 进入实例的「模组」页面
2. 找到要启用的模组
3. 点击「启用」

#### 禁用模组
1. 进入实例的「模组」页面
2. 找到要禁用的模组
3. 点击「禁用」

### 下载管理

#### 添加下载任务
1. 进入「下载」页面
2. 点击「+」按钮
3. 输入下载链接

#### 暂停/取消下载
- 在下载列表中找到任务
- 点击「暂停」或「删除」

### 游戏启动设置

#### 调整内存
1. 点击「启动」按钮旁的「⚙️」图标
2. 调整最小/最大内存
3. 点击「确定」

#### JVM 参数
- 在启动设置中添加自定义 JVM 参数

## 故障诊断

### 问题：无法找到 Java
**解决方案**：
1. 检查是否已安装 JDK 8-25
2. 运行 `java -version` 验证安装

### 问题：游戏启动失败
**可能原因**：
1. Java 版本不兼容
2. 内存分配不足
3. 实例损坏

**解决方案**：
1. 尝试调整 Java 版本
2. 增加内存分配
3. 重新创建实例

### 问题：模组无法加载
**解决方案**：
1. 检查模组是否与游戏版本兼容
2. 重新启用模组
